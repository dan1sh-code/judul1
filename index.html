Tentang Aplikasi

Interaktivitas murni berbasis JavaScript dan DOM API tanpa library eksternal.

Aplikasi ini adalah kelanjutan dari Praktikum 2. Pada tahap ini, halaman web telah dilengkapi logika pemrograman interaktif di sisi klien: validasi form, penambahan data instan tanpa muat ulang halaman, penghapusan data dengan konfirmasi, pencarian langsung (*live search*), dan pembaruan badge counter secara *real-time*.
