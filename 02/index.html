Tentang Aplikasi

Fondasi visual dan tata letak responsif menggunakan CSS murni.

Sistem Informasi Data Mahasiswa ini merupakan proyek pembelajaran berkelanjutan pada mata kuliah Pemrograman Web. Pada pertemuan ke-2 ini, seluruh struktur HTML5 yang dibuat pada Praktikum 1 dipercantik tampilannya menggunakan CSS murni dengan penerapan CSS Variables, Flexbox, CSS Grid, dan Media Queries untuk menjamin kompatibilitas multi-device (Desktop, Tablet, Mobile).

Informasi lebih lanjut tentang standar teknologi web modern dapat dipelajari pada Dokumentasi Pengembang Web MDN ↗.
